## 四条演化线索

### 1. 反合理化系统——持续的军备竞赛

从 v3.2.2 的 "1% rule" 开始，每个版本几乎都在增强防御：
- v3.2.2: 借口反驳表（8 条）
- v4.0.3: "I know what that means" 借口
- v4.3.0: `<HARD-GATE>` + EnterPlanMode 拦截
- v5.0.6: inline self-review（消除 subagent 捷径）
- v5.1.0: CLAUDE.md agent 指南（把防御从"使用 plugin"延伸到"贡献给 plugin"）

### 2. 跨平台扩展——持续的适配

- v3.5.0: OpenCode
- v3.3.0: Codex（实验性）
- v4.1.0: OpenCode 原生 skill 系统
- v4.2.0: Codex 原生 skill 发现
- 每次新平台都带来一轮新适配工作

### 3. 复杂度加→减循环

brainstorming: 简→繁（v4.3.0 加 HARD-GATE）→ 简（v3.4.0 从 6 阶段删到对话式）
review loop: 繁→简（v5.0.4 从 5 次减到 3 次，v5.0.6 从 subagent 减到 inline）

模式：先加结构 → 发现太 rigid → 用不同的方式加回 enforcement

### 4. 从个人配置到工业级系统

v2 时代：从 Jesse Vincent 的个人 CLAUDE.md 提取模式
v5 时代：5 平台、14 skill、完整测试框架、贡献者防御系统、1180 行 release notes

一条清晰的轨迹：个人经验 → 可复用 pattern → 系统化方法论 → 防御滥用
